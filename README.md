# Bedlam Theatre Vectorworks File

Currently maintained by Leon Lee

https://wiki.bedlamtheatre.co.uk/craft/vectorworks

## How to use
1. In the file selection, click bedlam-v2.vwx, or [Click Here](/bedlam-v2.vwx)
2. Click "Download Raw file" in the upper right hand corner

## Other useful files
In the Resources folder, you'll find:
- `bedlam-resources.vwx` which has a bunch of useful stuff such as a standard title block (the VWX ABTT one is very minimal) as well as bedlam customised fixtures with UK standard plugs and such. Place this in a folder called `[USER FOLDER]\Libraries\Bedlam Resources`
- `CableConnectors.xml` which has a re-ordered cable connectors list, as well as cables such as Neutrik branded ones as VWX are legally unable to use them [quite funny actually](https://forum.vectorworks.net/topic/121796-changing-electrical-connectors-on-fixtures-and-accessories/#findComment-563180). Place this in the following folder: `[USER FOLDER]\Libraries\Entertainment\Power\Cable Tools`

To use these, you will need to put the files in your User folder, which you can locate from the Vectorworks Preferenes. By default it is located at `%Appdata%\Nemetschek\Vectorworks\2026\` or similar. 

## Detailed file structure [sort of legacy right now]
- bedlam-auditorium.vwx is a self-contained file with anything you will need to create a rig.
- In the Reference Files folder, there is a file called conversion.vwx which you can import into a file (very right tab on the bottom right) and load up either Pippin 2019's conversion ,or Road 2025's conversion.
- There is also a file called bedlam-theatre.vex which is supposed to be an all inclusive file, and includes floor plans for the entire building (and not much else as of now)
